# Colnet

Вітаю вас в проекті мультиплатформенного електронного щоденника

> ### Статус Colnet
>
> Colnet все ще є прототипом і не має стабільної версії

## Цілі

Головноми цілями цього проєкту є:

- Створення е-щоденника з приємним і легким інтерфейсом
- Надати досвід групової роботи над проєктом
- Створити єдину мережу коледжу для доставки інформації, повністю розроблену і керовану студентами.
